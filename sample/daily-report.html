How this report scores health

Headline figures are the last 5-minute bucket. The window ends 2026-09-28 15:00 UTC, which is 08:00 Pacific. Peaks are supporting. Timestamps in the file are UTC epoch seconds. Labels and hover times use America/Los_Angeles. A missing sample is a gap in the line. The chart does not connect across it.

  • SQL and App Service plan CPU: warning 70%, critical 85%.
  • Queue depth: warning 1, critical 10.
  • Failure rate: warning 1%, critical 3%, only when the 5-minute bucket has at least 50 requests.
  • Dealer-site p95 latency: critical at 2,000 ms.
  • Azure AI Search throttled queries: critical at 0.1%.
  • CRM container restarts: any restart in a 5-minute bucket is critical.
  • Notification dead letters: any count above 0 is critical.

Charts that have a threshold keep that line on the scale, so a calm series can sit low in the plot.

Every number in this file is synthetic fixture data for a design review. Nothing here was measured from Production on 2026-09-28. The SQL shape illustrates the known pattern that recent days run hot.

This file is the artifact that would be uploaded to Azure Blob Storage; it stands alone when opened and does not call a database, collector, or network service.
